# Resonance v1.6.0

Resonance v1.6.0 improves downloads, playlist management, playback controls, and platform integration on Windows and Android.

## Highlights

- Added complete playlist management: create, rename, delete, switch, and persist custom playlist names.
- Restored automatic importing after YouTube downloads on Windows.
- Improved Android YouTube downloading and in-app audio conversion.
- Added album-cover artwork to Android media notifications and lock-screen controls.
- Made Windows shutdown faster and more reliable.
- Improved Windows media-key and taskbar playback controls.

## Playback and interface improvements

- Restored the last playing track and playback preferences between sessions.
- Persisted volume, speed, pitch, loop, and shuffle settings.
- Improved seeking, reordering, current-track navigation, and track-list feedback.
- Refined album-cover presentation and player controls.
- Added the Resonance startup audio and animation.

## Downloads

- Windows downloads now detect and import completed audio files reliably, including existing downloads and filenames containing Unicode punctuation.
- Android downloads no longer depend on desktop FFmpeg executables and preserve track metadata and cover artwork during conversion.
- Download progress and error handling are more reliable on both platforms.
