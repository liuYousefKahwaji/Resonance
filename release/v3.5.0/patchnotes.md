# Resonance 3.5.0

- Added author pages. Click an author's name in Discover or the stream player to browse their songs, sort by Newest, Oldest or Popular, and see views and likes when available. Start playback from any song, or shuffle the author's tracks.
- Added a language selector in Settings, starting with Arabic, with translated menus and right-to-left layouts.
- Improved YouTube browser connections on Windows. Resonance now tries your default browser directly, including Firefox and supported browsers such as Chrome, Edge and Brave. Browsers that protect their sessions can use the optional Resonance connector, with setup guidance when needed.
