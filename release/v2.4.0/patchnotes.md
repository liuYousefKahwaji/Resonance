# Companion controls, smarter suggestions, and a smoother Windows experience
(solves #41, #42, #43, and #44)

## Companion controls: (#41)
- added mute and deafen buttons to the Android Companion remote
- Windows can send your Discord mute and deafen shortcuts without sharing Discord account or status information
- shortcuts can be recorded, tested, restored, and saved for later

## Suggested Music: (#42)
- suggestions load sooner and provide a more varied mix of artists
- refresh produces a new, repeatable set of recommendations
- versions of songs already in the playlist, including slowed, reverb, lyric, and official-audio uploads, are left out
- empty playlists, failed searches, and no-result searches now have clear next actions

## Streams and playback: (#43)
- returning from a search preview keeps the search results ready to use
- stream artwork is kept when importing, transferring, or saving a track
- stream artwork is shown in playlists and the player, with a small badge to distinguish streams from local files
- stream visualizers remain smooth without downloading or decoding the stream a second time

## Windows experience: (#44)
- added an optional Windows-native control style, enabled by default
- kept the existing Resonance style available as a fallback
- improved Windows spacing, buttons, menus, focus states, sliders, and scrollbars

## Compatibility and reliability:
- existing playlists, saved metadata, and Companion pairings continue to work
- Android keeps its existing visual style
